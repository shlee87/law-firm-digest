<objective>
Implement cross-day retry of failed Gemini summaries.

Purpose: When Gemini returns 429 (free-tier RPD exhausted), that item gets summaryModel==='failed' and is marked seen — so it can never be re-fetched. But daily RPD resets at midnight PT, and the pipeline uses only ~2% of budget each day. This feature stores the summarize input on failed items and re-tries on subsequent daily runs using the spare quota, capped at 3 total attempts.

Output:
- PendingItemSchema with two new optional fields (backward-compatible with .strict())
- updatePending() exported from pending.ts for in-place item mutation
- Retry pre-pass at the start of runDaily's summarize stage
- toPendingItem stores summaryBody when summaryModel==='failed'
- 4 new vitest tests covering: recovery, CAP stop, backward-compat, weekly-never-summarizes
</objective>

   ```typescript
   // Retry pre-pass: re-summarize previously-failed items using stored summaryBody.
   // Runs before new-item summarize so quota is consumed from the same daily budget
   // window. CAP = 3 total attempts.
   if (!skipGemini) {
     const prePending = await readPending();
     const toRetry = prePending.items.filter(
       (it) => it.summaryModel === 'failed' && (it.summaryAttempts ?? 1) < 3,
     );
     if (toRetry.length > 0) {
       const retryLimit = pLimit(settings.gemini.concurrency);
       const updatedItems = [...prePending.items];
       await Promise.all(
         toRetry.map((failedItem) =>
           retryLimit(async () => {
             const body = failedItem.summaryBody ?? '';
             if (!body.trim()) return; // guard: no body stored, skip silently
             // Construct a minimal NewItem for summarize() — it only needs the fields
             // used by buildPrompt (firmId, title, url, language) and the spread in
             // the catch branch (all SummarizedItem fields except summary_ko etc.).
             const newItemProxy = {
               firmId: failedItem.firmId,
               title: failedItem.title,
               url: failedItem.url,
               publishedAt: failedItem.publishedAt,
               language: failedItem.language,
               description: body,   // needed by summarize caller contract
               isNew: true as const,
             };
             const result = await summarize(
               newItemProxy,
               body,
               {
                 primary: settings.gemini.primary_model,
                 fallback: settings.gemini.fallback_model,
               },
               settings.prompt,
             );
             const idx = updatedItems.findIndex((it) => it.url === failedItem.url);
             if (idx === -1) return;
             const prev = updatedItems[idx];
             if (result.summaryModel !== 'failed') {
               // Success: update in-place, drop summaryBody to keep pending lean
               updatedItems[idx] = {
                 ...prev,
                 summary_ko: result.summary_ko,
                 summaryConfidence: result.summaryConfidence,
                 summaryModel: result.summaryModel,
                 summaryError: undefined,
                 summaryBody: undefined,
                 summaryAttempts: (prev.summaryAttempts ?? 1) + 1,
               };
             } else {
               // Still failed: keep summaryBody, bump attempts
               updatedItems[idx] = {
                 ...prev,
                 summaryAttempts: (prev.summaryAttempts ?? 1) + 1,
               };
             }
           }),
         ),
       );
       await updatePending(updatedItems);
     }
   }
   ```
